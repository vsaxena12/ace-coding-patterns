### Common LLD problems you should know

1. Design a Parking Lot
    Design a parking lot system that supports different vehicle types, spot assignment, entry/exit, tickets, and billing.  
2. Design a Vending Machine
    Design a vending machine that supports product selection, inventory, coin/cash handling, refunds, and dispensing.  
3. Design an Elevator System
    Design an elevator control system for multiple elevators, floor requests, scheduling, and movement logic.  
4. Design an ATM
    Design an ATM system that supports authentication, withdrawal, deposit, balance inquiry, fund transfer, and cash inventory handling.  
5. Design a Library Management System
    Design a library system with books, members, catalog/search, issue/return, reservations, and fines.  
6. Design a Meeting Scheduler / Calendar
    Design a meeting scheduler with users, rooms, time slots, invitations, conflicts, and notifications.  
7. Design a Movie Ticket Booking System / BookMyShow
    Design a movie booking system with theatres, shows, seats, reservations, concurrency for seat locking, payments, and confirmations.  
8. Design a Car Rental System
    Design a car rental platform with vehicle inventory, branches, reservations, pickup/drop-off, and payments.  
9. Design an Airline Management / Flight Booking System
    Design a flight booking system with flights, seats, reservations, cancellations, schedules, staff, and payments.  
10. Design a Chess Game
    Design a chess game with board, pieces, move rules, turns, game state, and win conditions.  
11. Design an Online Bookstore
    Design an online bookstore with catalog, search, cart, checkout, inventory, and orders.  
12. Design a Splitwise / Expense Sharing App
    Design an expense-sharing system with users, groups, balances, splits, settlements, and history. This one is widely used in interview prep, though it was not explicitly listed in the sources above, so I’d treat it as common-but-not-confirmed by these specific sources.
13. Design a Snake and Ladder Game
    Design the board, dice, players, turn logic, snakes/ladders, and game completion. Common in OOD practice sets, but not explicitly listed in the sources above.
14. Design a Deck of Cards / Card Game
    Design cards, deck, shuffle, draw, hands, and game rules. Common classic OOD practice prompt.
15. Design a Jukebox / Music Player
    Design songs, playlists, queue, users, payment/subscription, and playback controls. Common classic OOD prompt.
16. Design a Hotel Management / Room Booking System
    Design rooms, booking, check-in/check-out, availability, billing, and services. Common OOD practice prompt.
17. Design a Restaurant / Table Reservation System
    Design tables, reservations, menu, order tracking, billing, and staff assignment. Common OOD practice prompt.
18. Design a Shopping Cart / E-commerce Order System
    Design products, cart, checkout, inventory, payments, and order state transitions. Common OOD practice prompt.
